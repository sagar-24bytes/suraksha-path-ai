# 🛠️ Hardware Specification & Deployment

*SurakshaPath AI — Embedded Hardware Layer*

## Overview

This directory contains deployment specifications, pin mapping diagrams, target MCU documentation, and hardware integration guides for deploying SurakshaPath AI firmware onto physical microcontrollers.

## Document Index

- `supported_boards.md` — Microcontroller target specs (ESP32, ESP8266, STM32, RP2040)
- `pin_mapping.md` — Sensor input and Neopixel RGB LED output pin assignments
- `deployment_notes.md` — Flashing MicroPython image and deploying firmware scripts
- `simulation_vs_hardware.md` — Hardware bridge architecture mapping `MockTransport` to physical transport
